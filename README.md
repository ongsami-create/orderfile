# OrderFile · 使用说明

> 一个工程单号（projNo），一条谁都不会覆盖的时间轴。

---

## 这个系统解决什么问题

业务员接了单，后面的设计师、下单员、安装师傅**对客户一无所知**。

以前要打电话问业务员，或者让客户把同样的话解释三遍。
现在每个人打开订单，第一眼就能看到：客户是谁、什么脾气、之前说过什么、有什么禁忌。

---

## 怎么用（3 分钟上手）

### 第一次

1. 打开网址 → **点自己的名字**进入（不用密码，内网用）
2. 右上角选**你现在是什么角色**（业务员 / 设计师 / 下单员 / 安装员）
3. 首页有红色数字的那单 = **等你处理**，点进去

### 手机上装

iPhone：Safari 打开 → 分享 → **添加到主屏幕**
Android：Chrome 打开 → 菜单 → **添加到主屏幕**

装完桌面有个图标，点开跟 App 一样，没有网址栏。

---

## 四个角色分别干什么

### 业务员（sales）

- **第一次**：客户画像（点几个标签：洁癖 / 不能抽烟 / 有小孩…）+ 客户说了什么 + 现场拍照 → 提交，交给设计师
- **提交确认**：客户签字了 → 拍签字件上传 → 系统自动交给下单员

### 设计师（design）

- 量尺数据、方案 V1/V2/V3、图纸 → 提交，交给**业务员**（要拿给客户看）

### 下单员（order）

- 交期、包装要求、给工厂的特殊工艺说明 → 提交，交给安装

### 安装师傅（install）

**只需要三步：**
1. 点桌面图标
2. 按那个绿色大按钮拍照
3. 点完成

**不用打字。** 现场有问题就点几个标签（墙面不平 / 缺件 / 门缝不对…），
没有就跳过。备注框可以留空。

---

## 三个要记住的规矩

### 1. 没上传东西，不能提交确认

业务员点「客户已签字」时，**必须上传签字件照片**，否则提交按钮是灰的。

原因：签字件是公司唯一的下单依据。客户以后翻脸说「我签的不是这一版」，
只有这张照片能说话。

### 2. 系统生成的确认单，业务员不能改

确认单上的**金额、交期**是从报价系统自动带出来的。

如果报价金额改了，订单上会红字提示「**金额已变更，需重新签字**」，
必须重新约客户签一次。

### 3. 客户不肯签字？

选「客户已书面确认」，上传 WhatsApp 截图。

订单上会标「**未经签字确认**」——下单员和安装员都看得到，
月底对账、出纠纷时这是不同的单。

## 红色是什么意思

| 看到 | 意思 |
|---|---|
| 🔴 `必须做` | 这条不做会出事，装的时候别漏 |
| 🔴 `已确认 V3` 变红 | 金额改了，要重新签字 |
| 红点 `● 3 条新` | 这单有 3 条新记录你还没看 |
| 虚线 `你上次看到这里` | 线以下是新的 |
| `已 N 天` | 这单卡在现在这个人手上 N 天了 |

## 常见问题

**Q：为什么不能选「这条属于哪个部门」？**
部门由系统按登录身份自动定。让人选的话，业务员手滑选了「设计」、
设计师选了「下单」，时间轴就乱了，以后没人敢信。
你能选的是「**指派给谁跟进**」—— 那是任务，不是分类。

**Q：我提交的东西有进展了，我怎么知道？**
首页第二个 tab「**我的提交**」，别人回过你、还等你回的单会出现在那里。

**Q：照片怎么传这么快？**
手机上传前会自动压缩（长边 1600px，约 300KB）。原图 3-5MB 直传要 30 秒，
传到一半人就跑了。

**Q：文件名我能改吗？**
不能，而且不需要 —— 文件名自动带 projNo，三个月后还能查出来是哪个单的。

**Q：数据会丢吗？**
订单记录**只追加，永不覆盖**。谁改了什么都能查。
删除只进回收站，能恢复。
